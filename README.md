# Thai Reading Lab · 泰语卡片阅读

> 把单词变成可以被真正读懂、听见、记住的一张张卡片。

## [立即开始学习 →](https://kinniuroudong-glitch.github.io/thai-reading-1-7/)

这是一个为泰语阅读与长期积累设计的轻量学习工具：打开即用，不需要安装，不需要注册，也不需要在复杂菜单里迷路。

每张卡片只处理一个词，但会把理解它所需要的关键线索放在同一个视线里：泰语词汇、中文释义、自然例句、整句翻译，以及逐词拆解。

## 使用方式

- 点击左右箭头，或使用键盘 `←` `→`，切换前后单词。
- 每次切换到新词，页面会自动朗读一次泰语发音。
- 勾选顶部“项目已完成”，记录当前项目的学习进度；每个项目会单独保存状态。
- 点击单词旁的声音按钮，可以再次朗读。
- 点击逐词翻译中的任意词块，可以单独听该词。
- 使用顶部项目选择器，在不同的 1000 词项目之间切换。

## 内容规模

- 当前收录 10,689 条泰语词汇与短语。
- 前 10 个项目各 1,000 词，第 11 个项目收录剩余词条。
- 每条内容包含例句、中文润色和逐词翻译，适合从“看懂”过渡到“读出来”。

## 设计理念

### 少一点噪音，多一点理解

页面不堆叠徽章、装饰和无关信息，让眼睛直接落在词、句子和语义关系上。

### 先建立语感，再补齐细节

先读完整例句，再用逐词卡片回看结构；你不只是记住一个中文意思，而是在逐渐熟悉泰语如何组织意义。

### 让复习保持连续

左右切换、自动发音、键盘操作和移动端滑动都围绕同一件事服务：让下一张卡片自然出现。

## 技术说明

本项目是一个单文件、静态、无后端的学习页面，使用浏览器内置的 Web Speech API 进行泰语朗读。页面可以直接通过 GitHub Pages 访问，也可以下载后离线打开。

如果浏览器第一次没有播放声音，先点击一次页面中的箭头或声音按钮，再继续切换即可；这是浏览器对网页自动播放语音的权限限制。
